# Changelog Format

This repository follows the principles of **Keep a Changelog** while aligning releases with **Semantic Versioning (SemVer)**.

Each release may contain the following sections:

- Added
- Changed
- Deprecated
- Removed
- Fixed
- Security

Not every release will include every section.
