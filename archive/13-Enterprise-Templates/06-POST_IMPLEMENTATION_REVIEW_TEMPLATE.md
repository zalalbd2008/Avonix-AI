# Enterprise Post-Implementation Review (PIR) Template

> "A successful implementation is not complete until its outcomes have been validated, measured, and documented."

---

# Purpose

This template defines the official Enterprise Post-Implementation Review (PIR) format for Avonix AI.

It provides a standardized framework for evaluating whether an implemented change achieved its intended objectives, delivered business value, maintained operational stability, and generated actionable lessons for continuous improvement.

---

# Philosophy

Post-implementation reviews should be:

- Evidence-based
- Objective
- Transparent
- Outcome-focused
- Improvement-oriented
- Governance-aligned
- Audit-ready

The purpose is to evaluate implementation effectiveness—not assign blame.

---

# Objectives

This template ensures:

- Consistent implementation reviews
- Validation of expected outcomes
- Business value measurement
- Risk reassessment
- Knowledge preservation
- Continuous improvement
- Executive visibility

---

# Scope

Applicable to:

- Major platform changes
- Infrastructure deployments
- AI model releases
- Security improvements
- Cloud migrations
- Product launches
- Database changes
- Enterprise transformation initiatives

# Executive Summary

Summarize:

- Implementation overview
- Overall outcome
- Business value delivered
- Key findings
- Executive recommendation

---

# Implementation Overview

Document:

- What was implemented
- Why it was implemented
- Planned implementation window
- Actual implementation window
- Teams involved

---

# Objectives vs Actual Outcomes

| Objective | Planned Outcome | Actual Outcome | Status |
|-----------|-----------------|----------------|--------|
| | | | |

Assess whether each objective was achieved.

---

# Success Criteria Validation

Evaluate:

- Functional objectives
- Performance objectives
- Security objectives
- Compliance objectives
- Customer objectives
- Operational objectives

Each criterion should include measurable evidence.

---

# Scope Review

Compare:

- Planned scope
- Delivered scope
- Deferred items
- Out-of-scope work
- Scope deviations

Document reasons for any variance.

---

# Schedule Performance

Record:

- Planned completion date
- Actual completion date
- Schedule variance
- Causes of delay (if applicable)

---

# Cost & Resource Review

Evaluate:

- Planned budget
- Actual expenditure
- Resource utilization
- Budget variance
- Financial observations

---

# Business Impact Assessment

Assess the implementation's effect on:

- Customers
- Revenue
- Operations
- Product
- Engineering
- AI Services
- Compliance
- Business continuity

---

# Operational Performance

Review:

- Service availability
- System stability
- Monitoring effectiveness
- Incident frequency
- Operational readiness
- Support workload

---

# Risk Review

Evaluate:

- Risks identified before implementation
- Risks encountered during implementation
- Residual risks
- Newly identified risks

Reference the relevant Risk Register entries where applicable.

---

# Incident Summary

If incidents occurred, document:

- Incident ID
- Severity
- Resolution status
- Customer impact
- Recovery summary

---

# Rollback Evaluation

If rollback was executed, record:

- Trigger event
- Rollback process
- Effectiveness
- Recovery duration
- Lessons learned

If rollback was not required, document why.

---

# Benefits Realization

Measure:

- Expected benefits
- Achieved benefits
- Business value delivered
- Strategic alignment
- Return on investment (where applicable)

---

# Stakeholder Feedback

Collect feedback from:

- Product
- Engineering
- Operations
- Security
- Customer Support
- Business Leadership
- Customers (if applicable)

Summarize key observations and recommendations.

---

# Lessons Learned

Capture:

- Successes
- Challenges
- Unexpected outcomes
- Improvement opportunities
- Best practices to reuse

Lessons should be actionable and measurable.

---

# Review Outcome

Select one outcome:

- Fully Successful
- Successful with Minor Improvements
- Partially Successful
- Requires Additional Work
- Unsuccessful

Provide justification for the selected outcome.
