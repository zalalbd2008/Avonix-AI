=== Avonix AI Connector ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.3.74
License: GPLv2 or later

Sends this site's form submissions to Avonix AI, where they become contacts in
the agency's CRM.

== Installation ==

1. Upload and activate the plugin.
2. Open Settings → Avonix AI.
3. Paste the connector key shown when the website was added in Avonix.
4. Save, then press "Test connection".
5. Add [avonix_form] to any page.

== What this plugin does not do ==

It holds no business logic. It stores a key, forwards submissions, and renders a
form. Everything else lives in the cloud, so behaviour can change without asking
every site to update.
